## 1. 只读查询控制器

状态通道 TCP `19204`，协议头版本 1，请求 API1000（16 字节头：同步 0x5A、版本、序号、长度、API、6 字节保留）。

```bash
python3 - <<'PY'
import socket, struct, json
H = struct.Struct('>BBHIH6s')
def recvn(s, n):
    b = b''
    while len(b) < n:
        p = s.recv(n - len(b))
        if not p: raise RuntimeError('连接提前关闭')
        b += p
    return b
s = socket.create_connection(('192.168.192.5', 19204), timeout=3)
s.sendall(H.pack(0x5a, 1, 1, 0, 1000, b'\0'*6))
sync, ver, seq, n, kind, res = H.unpack(recvn(s, H.size))
d = json.loads(recvn(s, n).decode('utf-8'))
print(d['current_map'], d['current_map_md5'])
PY
```

## 5. 坐标换算

`src/robot_move/src/localization/node.cpp:207`：

```
T_map_base = T_map_seer ∘ T_seer_robot ∘ T_seer_base
```

当前 `seer_localization.yaml` 的 `map_alignment` 为 0（未确认），`base_yaw_in_seer = +π/2`（已在 `seer_odometry_confirmed.yaml` 确认）。因此：

- 若 `map_alignment` 确为恒等，ROS `map` 帧与仙工地图帧重合，路径 x/y 可直接作为仙工坐标。
- base_link 朝向 = 仙工 API 朝向 + π/2；导航运动使用仙工朝向（路径切线）时不要再叠加该偏移。
- **`map_alignment_confirmed` 当前为 `false`，上述重合是假设，不是标定结果。**

## 6. 仙工 API 执行

通道与端口（`seer_types.hpp:25-32`）：

| 通道 | 端口 | 用途 |
| --- | --- | --- |
| Status | 19204 | 1000/1004/1020 查询 |
| Control | 19205 | 2010 速度 |
| Navigation | 19206 | 3055 平动、3056 转动 |
| Other | 19210 | DO 等 |

**方式一：逐段 3056 转 + 3055 平移**

对每段 `i -> i+1`：

1. 用 API1004 读取当前 `angle`，计算 `Δ = wrap(h_i - angle)`；
2. `|Δ|` 超阈值时发 3056：`{"angle": |Δ|, "vw": 0.1*sign(Δ), "mode": 1}`，轮询 1020 至完成；
3. 发 3055：`{"dist": d_i, "vx": 0.05, "mode": 1}`；`dist` 为绝对值，方向由 `vx` 正负决定，轮询 1020。

`mode: 1` 为定位模式，`0` 为里程模式。3055/3056 不能与 3057/3058 同时进行，新任务会取消当前任务。

双舵轮也可以不先转：对每段取 `Δ = wrap(h_i - 当前angle)`，令 `vx = v*cos(Δ)`、`vy = v*sin(Δ)`、`dist = d_i`、`mode = 1`，由轮系协调行进方向，车体姿态保持不变。该组合运动是否被当前固件接受需先用小速度验证。

**方式二：2010 速度 + 纯跟踪**

用前视点计算 `vx/vy/w`，Control 端口 19205 下发，duration 建议 ≤ 500 ms，并在调用侧实现超时停车。底盘为对角双舵轮，理论上支持 `vx/vy/w` 组合，但横移与旋转同时执行时的轮系协调、实际限速和 API 语义需现场验证；首次执行仍建议用方式一（先转再直行）。

- **未发送任何运动指令，未验证实车运动、到达精度和停车。**
- 控制器 `calibrated: false`，含义未确认。
