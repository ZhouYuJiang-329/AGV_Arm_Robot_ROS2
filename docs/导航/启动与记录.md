# 导航启动与记录

以下命令在工作区根目录执行。此文件整理的是当前现场用法，完整入口参数见[启动参数与配置关系](启动参数与配置关系.md)。配置原文件清单见[配置文件清单](配置文件清单.md)。

## 实机导航启动


在新终端中进入工作区并加载环境。控制器地址为 `192.168.192.5`，ROS 域为 `216`：

```bash
cd /home/zyj/Code/ROS2/AGV_new/AGV_ROS2_Control_Manager
export PATH="/usr/bin:$PATH"
source /opt/ros/jazzy/setup.bash
source install/setup.bash
export ROS_DOMAIN_ID=216
export ROS_AUTOMATIC_DISCOVERY_RANGE=LOCALHOST

ros2 launch agv_bringup agv_navigation_real.launch.py \
  mode:=execute \
  connection:=192.168.192.5 \
  map:="$PWD/maps/seer/20251120141209997_navigable.yaml" \
  params_file:="$PWD/docs/validation/seer_low_speed_2026-11-13/nav2_locked_arm_site.yaml" \
  guard_params:="$PWD/src/robot_move/config/navigation_guard.yaml" \
  localization_params:="$PWD/docs/validation/seer_low_speed_2026-11-13/localization_observe_site.yaml" \
  commissioning_file:="$PWD/src/agv_bringup/config/agv_navigation_commissioning.yaml" \
  reuse_lidar:=false \
  reuse_odometry:=false \
  reuse_localization:=false \
  reuse_description:=false \
  rviz:=true
```

这条命令新建采集、定位、TF、规划及执行节点，并打开 RViz；不会自动发送导航目标。执行链激活后，使用 RViz 的 `Navigation 2` 面板配合 `Nav2 Goal` 工具下发目标。

需要同步记录路径、速度和舵轮角度时，在另一个已加载同一工作区环境的终端执行：

```bash
/usr/bin/python3 tools/record_navigation.py --domain-id 216 --seer-ip 192.168.192.5
```

记录的启动、结束与回看方法见[导航过程记录与回看](../导航过程记录与回看.md)。


## RViz 下发导航目标

在 Panels → Add New Panel 中添加 `nav2_rviz_plugins/Navigation 2` 面板，工具栏添加 `nav2_rviz_plugins/GoalTool`（Nav2 Goal）。执行链激活后，通过 Nav2 Goal 设点并拖动确定目标朝向。原来的 2D Goal Pose 发到 `/planning_preview/goal`，只供观察模式预览路径。

面板的 Navigation/Localization 可能显示 unknown，因为当前使用自定义生命周期管理器及仙工定位；判断以实际生命周期、guard 诊断和任务反馈为准。不要为了消除 unknown 另外启动 AMCL。

## 记录停止与回看

手动开启的记录器在记录终端 Ctrl+C 即正常结束并保存，不会停止导航。默认最多一小时。后台记录按记录目录的 recorder.pid 核对进程身份后结束，具体方法见原[记录说明](../导航过程记录与回看.md)。

查看 `logs/navigation/latest.txt` 得到最近记录目录。`summary.json` 是任务及异常摘要，`overview.svg` 是实时更新的最新规划/实际轨迹图，`trajectory.csv` 为地图坐标点，`steering.csv` 为轮角及速度，`events.jsonl` 保留中间路径和诊断，`bag/` 保留原始话题。没有历史回溯能力，应在发导航目标前开启。

分析后生成的 `analysis/trajectory_review.png`、`analysis/steering_stop_go_review.png` 等属于离线复盘图，并非每次启动记录器都会自动产生。

原始 bag 含速度话题；离线读取文件，或在与实车隔离的 ROS 域回放，避免把历史指令发给正在运行的底盘。

## 编译与生效

- 修改 YAML：重启对应启动命令加载；无需编译。当前程序一般不会自动加载磁盘改动。
- 修改 C++ 保护节点：编译并重新加载工作区，再重启；不自动恢复之前的失败目标。
- 修改本机 symlink-install 指向的 Python 门禁：重启节点加载。

```bash
export PATH="/usr/bin:$PATH"
source /opt/ros/jazzy/setup.bash
source install/setup.bash
CMAKE_BUILD_PARALLEL_LEVEL=2 colcon build --symlink-install --packages-select robot_move --executor sequential
source install/setup.bash
```

## 只读检查示例

```bash
export ROS_DOMAIN_ID=216
ros2 param get /seer_localization min_confidence
ros2 param get /controller_server goal_checker.xy_goal_tolerance
ros2 param get /controller_server FollowPath.max_speed_xy
ros2 param get /controller_server FollowPath.Twirling.scale
ros2 lifecycle get /bt_navigator
ros2 lifecycle get /controller_server
```

这些命令只查询。磁盘值、文档快照和运行值应分别核对。
