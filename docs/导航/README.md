## 当前现场链路

```text
Nav2 控制器 → /navigation/cmd_vel_raw
           → 速度平滑器 → /navigation/cmd_vel_smoothed
           → 碰撞监测器 → /navigation/cmd_vel_guard
           → navigation_guard → 仙工 API2010 → 底盘

仙工定位 → map→odom；实际速度积分 → odom→base_link
机器人描述/雷达外参 → base_link→前后雷达
```

当前 IP 为 `192.168.192.5`，ROS 域为 `216`。实际 Nav2 参数来自 `docs/validation/seer_low_speed_2026-11-13/nav2_locked_arm_site.yaml`；实际定位参数来自同目录的 `localization_observe_site.yaml`。同名通用模板与历史验证配置可能有不同值，应以启动参数选中的文件为准。

地图图像、模型、可执行代码及原始运行记录保留原位置，索引中提供链接，不把文档整理变成部署路径迁移。

## 更新这些文档

修改原始配置后，从工作区根目录执行：

```bash
/usr/bin/python3 tools/export_navigation_config_docs.py
```

该脚本只刷新生成的配置清单、全部参数参考、原样快照和哈希，不启动 ROS、不连接车辆。人工编写的本页、启动说明、关键参数说明不会被覆盖，应在参数变更时同步修订。
