# 关键参数与修改位置

本页数值按 2026-11-20 磁盘配置核对，完整值见[全部参数参考](全部参数参考.md)。下文简称“现场 Nav2”为[nav2_locked_arm_site.yaml](../../docs/validation/seer_low_speed_2026-11-13/nav2_locked_arm_site.yaml)。

## 速度、加减速与转向

| 原文件与节点 | 参数 | 当前值 | 含义 |
| --- | --- | --- | --- |
| 现场 Nav2 / controller_server.FollowPath | min/max_vel_x、min/max_vel_y | 每轴 ±0.05 m/s | 全向速度采样范围 |
| 同上 | max_speed_xy | 0.05 m/s | 正常路径跟随的合成平移速度上限，约 5 cm/s |
| 同上 | max_vel_theta | 0.1 rad/s | 角速度上限，约 5.7°/s |
| 同上 | acc_lim_x/y；decel_lim_x/y | 0.1；-0.1 m/s² | 指令加减速约束 |
| 同上 | acc_lim_theta；decel_lim_theta | 0.2；-0.2 rad/s² | 角加减速约束 |
| 现场 Nav2 / velocity_smoother | max_velocity | [0.05,0.05,0.1] | 顺序为 vx、vy、w |
| 同上 | min_velocity | [-0.05,-0.05,-0.1] | 各轴反向范围 |
| 同上 | max_accel / max_decel | [0.1,0.1,0.2] / [-0.1,-0.1,-0.2] | 平滑器约束，需与控制器协调 |
| 同上 | smoothing_frequency / feedback | 20 Hz / OPEN_LOOP | 指令平滑，不能当成底盘运动反馈认证 |
| navigation_guard.yaml | max_linear_speed / max_angular_speed | 0.15 m/s / 0.2 rad/s | 最终保护边界，不代表正常导航就在此速度运行 |

调整导航速度要同时考虑 FollowPath、velocity_smoother 和 guard。静态校验按平滑器 XY 范围的最大合成速度检查：例如每轴 0.10 m/s，最大合成约 0.141 m/s，仍低于当前 guard 的 0.15；每轴 0.15 则合成约 0.212，会超过该边界。速度提高后的停车响应需要重新记录比较。

上一轮停走主要与转舵同步，单纯提高 max_speed_xy 不会消除转舵等待。

## 位置到点与末端朝向

| 现场 Nav2 路径 | 当前值 | 含义 |
| --- | --- | --- |
| controller_server.goal_checker.xy_goal_tolerance | 0.15 m | 平面目标点半径，不是各轴独立误差，也不是障碍距离 |
| controller_server.goal_checker.yaw_goal_tolerance | 0.1 rad | 最终朝向容差，约 5.7° |
| controller_server.goal_checker.stateful | true | 位置条件满足后保持，继续判定朝向 |
| controller_server.FollowPath.xy_goal_tolerance | 0.15 m | DWB 末端旋转窗口，需与最终位置要求协调 |
| controller_server.FollowPath.trans_stopped_velocity | 0.01 m/s | 末端旋转评分使用的低平移速度阈值 |
| planner_server.GridBased.tolerance | 0.2 m | 规划器求解终点容差；不是控制器的物理到点判定 |

旧配置最终要求 0.10 m、DWB 窗口 0.15 m，存在停在 10～15 cm 时的冲突，已统一至 0.15 m。历史快照中仍可能出现 0.10 m，不要用于当前数值判断。

## 途中调角评分

当前在 FollowPath 中：PathAlign.scale=0、GoalAlign.scale=0、Twirling.scale=5，critics 已包含 Twirling；PathDist=24、GoalDist=20、RotateToGoal=24 保留。目的是允许全向平移跟随位置路径，减少因对齐路径而产生的不必要转车身，终点朝向仍有要求。

Twirling=5 是首轮试验权重，并非厂家标定。DWB 当前没有显式舵轮角/转速约束；优化效果以带轮角记录的同路线对比为准。参数背景见[双舵轮调角优化](../双舵轮导航途中调角参数优化_2026-11-18.md)。

## 车体轮廓与避障

现场 Nav2 的 global/local costmap 均为：

- footprint：X=±0.375 m，Y=±0.625 m。base_link 长边沿 Y；范围为 0.75×1.25 m，按现场固定姿态底盘范围加边缘余量。
- 分辨率 0.05 m；local 为 odom 下 6×6 m 滚动窗口，10 Hz 更新；global 为 map 下 2 Hz 更新。
- 前后雷达分别 `/scan_front`、`/scan_back`，保持双观测，不将未知束冒充自由空间。
- inflation_radius=1.65 m、cost_scaling_factor=3；影响障碍代价分布与绕行空间，不等于实际车体轮廓。

碰撞监测器在速度平滑器与 guard 之间：

| 参数 | 当前值 |
| --- | --- |
| FootprintApproach.action_type | approach |
| FootprintApproach.time_before_collision | 1.5 s |
| FootprintStop.action_type | stop |
| FootprintStop.points | X=±0.525 m，Y=±0.775 m |
| FootprintStop.min_points | 3 |
| source_timeout | 0.6 s |
| stop_pub_timeout | 1.0 s |

停车区域在已加余量的 footprint 外再扩 0.15 m。不要将它和 0.15 m 的目标到点半径混为同一参数。机械臂/工具姿态变化会改变轮廓依据。

## 定位与 TF

实际定位文件：[localization_observe_site.yaml](../../docs/validation/seer_low_speed_2026-11-13/localization_observe_site.yaml)。

| 参数 | 当前磁盘值 | 含义 |
| --- | --- | --- |
| min_confidence / require_confidence | 0.1 / true | 用户指定的定位质量门槛；调低不代表定位误差自动变小 |
| expected_map / expected_map_md5 | 20251120141209997 / 342c6d27a3ad34d10d2bd44899c4578b | 仙工地图身份，不是 ROS 文件名推断 |
| map_alignment_confirmed / base_transform_confirmed | true / true | 现场确认声明 |
| base_x/y_in_seer_m / base_yaw_in_seer_rad | 0 / 1.5707963267948966 | base 相对仙工参考轴的变换，需与里程计/guard 一致 |
| tf_publish_mode | bounded_odom_hold | 已接受定位在新鲜里程计时刻提供有界 TF 支持 |
| request_rate_hz | 2 Hz | 查询节奏，不等于保证每次都接受新定位 |
| max_query_latency_sec / max_sample_age_sec | 0.6 / 0.8 s | 查询与已接受定位有效期限 |
| max_odom_bracket_sec / max_odom_age_sec | 0.4 / 0.5 s | 对齐里程计的跨度与有效期限 |
| max_correction_rotation_rad | 0.1 rad | 当前现场用户调整后的旋转修正跳变门槛；通用模板仍为 0.5 |
| max_correction_translation_m | 0.5 m | 平移修正跳变门槛 |
| jump_recovery_samples | 3 | 持续修正的稳定接受次数规则 |

map→odom 由仙工定位节点发布；odom→base_link 由速度积分里程计发布，不能另外启动 AMCL 或静态 map→odom 掩盖定位拒绝。API1004/1005 的 create_on 仍不作为原始测量时间。

里程计当前使用 seer_odometry_confirmed.yaml，5 Hz 查询，1 s 请求/过期上限，最大积分间隔 0.6 s；间隔未知时丢弃积分基线而不是伪造位移。雷达使用 seer_lidar.yaml，5 Hz 查询，1 s 请求/过期上限，前后各 541 个角度格点（-135°～135°、0.5°步长）。

挂载文件 lidar_mounts.yaml 中：前雷达 (-0.295,-0.55,-0.24) m、yaw=-135°；后雷达 (0.295,0.55,-0.24) m、yaw=54°。z 是相对 base_link，高度/光心等仍以该文件的校准说明为准，不把历史候选值直接当默认外参。

## 停车、故障与执行门禁

navigation_guard.yaml：cmd_vel_timeout=0.5 s、controller_duration_ms=800 ms、request_timeout_ms=150 ms、stop_attempts=2；心跳必须在 0.4 s 内新鲜。scan/odom 超时为 0.6 s，动态 TF/定位为 0.8 s；停车确认要求线速度低于 0.01 m/s、角速度低于 0.02 rad/s，并持续 0.5 s。

运动指令断流进入 StopRequested，输入或通信失效进入 Fault；数据恢复不会自动重放旧速度。普通零速进入 CommandedStop，等待零速应答后，只接纳后续新指令。现场审核文件还绑定 ROS 地图 YAML/图像 SHA256 和仙工地图身份。

controller_server.progress_checker：required_movement_radius=0.05 m、movement_time_allowance=20 s。未达进展要求可能触发行为树恢复；不要把它与轮角到位判断混同。

## 参数修改后如何确认

先刷新配置清单，再重启加载并只读查询运行值。使用同一套记录比较任务结果、停稳、路径偏离、转舵/静止时间。文档快照、磁盘文件和运行参数是三个不同层次。
