# AGV_ROS2_Control_Manager 话题 / 服务 / 动作 清单

> 本清单由**源码字面量 + 配置(yaml/srdf)静态整理**生成（未运行真机），覆盖仓库内各功能包对外暴露与消费的所有 ROS 2 通信接口。
> 名称均以代码为准（大多不带前导 `/`）；在默认根命名空间下等于全局绝对名。QoS 未特殊说明均为默认 RELIABLE + KeepLast(10)。

---

## 0. 快速总览

- 自定义 **service / action**：**无**（全仓无 `create_service`/`create_client`/自定义 srv/action）。服务来自 `ros2_control` controller_manager，动作来自 3 个 `JointTrajectoryController` 与 MoveIt move_group（见 §3）。
- **话题分四类**：① 机械臂控制/反馈（`agv_hardware`）；② 底盘驱动（`robot_move` + `agv_bridge`）；③ 视觉与路径规划（`camera` + `pathplanner`）；④ ros2_control/MoveIt 标准话题。

---

## 1. 话题清单（按节点分组）

> 图例：**P** = 该节点发布；**S** = 该节点订阅。

### 1.1 `agv_hardware`（AgvHardwareInterface，ros2_control 硬件插件）

| 话题 | 类型 | 方向 | 内容 / 语义 |
|------|------|------|------------|
| `arm_joint_states` | `std_msgs/Float64MultiArray` | P | 机械臂当前关节角（12 关节），随控制环周期发布 |
| `arm_cartesian_pose` | `std_msgs/Float64MultiArray` | P | 末端(ee)笛卡尔位姿反馈 `[x,y,z,rx,ry,rz]`；**对外（上位机/PAUT）的关键反馈** |
| `arm_operation_state` | `std_msgs/Int32` | P | 机械臂运行状态：0=静止，9=运动中（rokae OperationState）；状态机握手用 |
| `/click_point` | `geometry_msgs/PointStamped` | P | 相机图像点击点（frame=`camera_color_optical_frame`），由机械臂命令转发 |
| `cmd_arm_joint` | `std_msgs/Float64MultiArray` | S | 关节角指令（6 元）→ `sendJointCommand` |
| `cmd_arm_cartesian` | `std_msgs/Float64MultiArray` | S | **末端 ee 笛卡尔目标位姿**（6 元）→ `sendCartesianCommand("linear")`；供 PAUT/上位机下发 |
| `/path_planner/cartesian_path` | `geometry_msgs/PoseArray` | S | 规划路径点列；**当前处理器仅打日志、执行循环被注释**（见 README 已知事项） |

### 1.2 `robot_move`（UniversalRobotDriver，通用底盘驱动）

| 话题 | 类型 | 方向 | 内容 / 语义 |
|------|------|------|------------|
| `agv_pose` | `geometry_msgs/Pose2D` | P | 底盘位姿 `x/y/theta`（20ms 定时器，节拍控制发布） |
| `cmd_vel` | `geometry_msgs/Twist` | S | 底盘速度指令 `vx,vy,wz` → `setVelocity` |
| `scan_config` | `geometry_msgs/Twist` | S | 扫查配置：`x/y/z` = speed/distance/precision → `setScannerConfig` |
| `scan_ctrl` | `std_msgs/Empty` | S | 触发一次扫查（起线程执行 `scannercontrol`） |
| `robot_distance_move` | `geometry_msgs/Twist` | S | 定长平移：`linear.z`=距离，`linear.x/y`=速度 → `movebydistance` |
| `robot_rotate_move` | `geometry_msgs/Twist` | S | 定角旋转：`angular.z`=角度，`angular.y`=角速度 → `rotatebyangle` |

> 支持 AGV / 气吸附 / 涵道 / 磁吸附四种底盘，`robot_type` 参数切换；话题接口统一。

### 1.3 `agv_bridge`（BridgeManager，中介）

| 话题 | 类型 | 方向 | 内容 / 语义 |
|------|------|------|------------|
| `cmd_vel` | `geometry_msgs/Twist` | P | 底盘速度（由上位机底盘命令或硬件接口转来） |
| `robot_status` | `std_msgs/String` | P | 机器人状态 JSON 字符串 |
| `radar_heartbeat` | `std_msgs/Header` | S | 雷达心跳；2s 内无心跳判离线 |
| `camera_heartbeat` | `std_msgs/Header` | S | 相机心跳；同上 |

### 1.4 `camera`（AstraSNode，RGB-D 相机驱动）

| 话题 | 类型 | 方向 | 内容 / 语义 |
|------|------|------|------------|
| `color/image_raw` | `sensor_msgs/Image` | P | 彩色图（rgb8），伴 `color/camera_info` |
| `color/camera_info` | `sensor_msgs/CameraInfo` | P | 彩色相机内参 |
| `depth/image_raw` | `sensor_msgs/Image` | P | 深度图（16UC1），伴 `depth/camera_info` |
| `depth/camera_info` | `sensor_msgs/CameraInfo` | P | 深度相机内参 |
| （静态 TF） | — | P | `arm2_tool_link → camera_color_frame/camera_depth_frame`（Eye-in-Hand） |

> IR 通道关闭，不发布点云。另有可选 `video_web_server.py`（订阅 `/color/image_raw`，经 HTTP 推流，非 ROS 话题）。

### 1.5 `pathplanner`（PathPlannerROS2Node，SAM2 路径规划）

| 话题 | 类型 | 方向 | 内容 / 语义 |
|------|------|------|------------|
| `/path_planner/path_3d` | `sensor_msgs/PointCloud2` | P | 3D 路径点（字段含 x/y/z/rx/ry/rz，frame=`camera_color_frame`） |
| `/path_planner/cartesian_path` | `geometry_msgs/PoseArray` | P | 末端 ee 路径点列（frame=`arm2_cartesionbase_link`，含工具补偿）→ 供 PAUT/执行端 |
| `color/image_raw` | `sensor_msgs/Image` | S | 订阅相机彩色图（参数 `color_topic`） |
| `depth/image_raw` | `sensor_msgs/Image` | S | 订阅相机深度图（参数 `depth_topic`） |
| `/click_point` | `geometry_msgs/PointStamped` | S | 点击选点，触发整条分割+规划管线 |
| `test_click_publisher`（工具） | `geometry_msgs/PointStamped` | P | 向 `/click_point` 发测试点（调试用） |

> 话题名均可用 launch/参数覆盖（默认见 `params.yaml` / launch 内 override：`/color/image_raw`、`/depth/image_raw` 等）。

### 1.6 ros2_control / MoveIt 标准话题（随 `agv_bringup/agv.launch.xml` 或 move_group 提供）

| 话题 | 类型 | 提供方 | 说明 |
|------|------|--------|------|
| `/joint_states` | `sensor_msgs/JointState` | `joint_state_broadcaster` | 全关节状态（控制器装配时发布） |
| `/robot_description` | `std_msgs/String`（参数） | robot_state_publisher / move_group | URDF，非话题而是参数 |
| move_group 显示/规划话题 | MarkerArray 等 | MoveIt move_group | `/move_group/display_planned_path` 等（标准，随配置） |

## 2. 服务（Service）

仓库**未自定义**服务。运行期由 `controller_manager`（ros2_control）提供标准服务，命名空间在 `/controller_manager` 下：

`list_controllers`、`list_controller_types`、`load_controller`、`unload_controller`、`switch_controller`、`set_hardware_component_state` 等（launch 中 spawn 控制器即通过该类服务完成）。MoveIt 亦有 `/move_group` 相关服务，按标准配置提供。

---

## 3. 动作（Action）

仓库**未自定义** action。三类动作来自 ros2_control/MoveIt 配置：

| 动作 | 类型 | 提供方 | 说明 |
|------|------|--------|------|
| `/arm1_controller/follow_joint_trajectory` | `control_msgs/FollowJointTrajectory` | `arm1_controller`（JTC） | 左臂关节轨迹 |
| `/arm2_controller/follow_joint_trajectory` | 同上 | `arm2_controller`（JTC） | 右臂关节轨迹 |
| `/agvBase_controller/follow_joint_trajectory` | 同上 | `agvBase_controller`（JTC） | 升降+回转 |
| `/move_action` 等 | `moveit_msgs/MoveGroup` | move_group | MoveIt 规划/执行（随配置，`moveit_controllers.yaml` 将规划结果转发给上述 follow_joint_trajectory 动作） |

> MoveIt 规划组：`arm1` / `arm2` / `agvBase`；控制器绑定见 `agv_moveit_config/config/moveit_controllers.yaml`。

## 4. 关键对外接线图（谁能连谁）

```
上位机/PAUT(感控) ──cmd_arm_cartesian──► agv_hardware ──rokae SDK──► 臂
agv_hardware ──arm_cartesian_pose / arm_operation_state / arm_joint_states──► 上位机/PAUT
pathplanner ──/path_planner/cartesian_path──► {agv_hardware(监听,不执行), PAUT arm_control(执行)}
camera ──color|depth/image_raw ──► pathplanner
上位机 ──cmd_vel(经 agv_bridge) / robot_distance_move...──► robot_move ──agv_pose──► 上位机
agv_bridge ◄──radar_heartbeat/camera_heartbeat── 各设备心跳
```

## 5. 话题跨仓库关系（提示）

与另一独立仓库 `PAUT_ros2`（超声感控）真正相连的是 4 条主线：`cmd_arm_cartesian`、`arm_cartesian_pose`、`arm_operation_state`、`path_planner/cartesian_path`。详见 [`docs/AGV_PAUT_集成契约.md`](AGV_PAUT_集成契约.md)。

## 6. 备注

- **节点命名空间**：所有节点默认根命名空间，无 remap —— 话题名即字面量（如 `cmd_vel` ≡ `/cmd_vel`）。
- **发布频率**：`agv_hardware` 三条反馈随 control loop 周期（update_rate 1000Hz，见 `agv_bringup/config/ros2_controllers.yaml`）；其余话题按事件/定时器（如 `agv_pose` 20ms 定时器节拍）。
- **验证方法**（运行期）：`ros2 node list`、`ros2 topic list -t`、`ros2 topic info <名>`、`ros2 action list -t`、`ros2 service list`。
