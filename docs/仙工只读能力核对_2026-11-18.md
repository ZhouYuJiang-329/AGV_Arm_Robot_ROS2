## goPath 的能力与边界

实际 Python 实现调用 `r.loc()` 取得当前位置，建立当前点到目标点的两点路径，并将 `maxSpeed/maxRot` 传给内部路径引擎；加减速参数也会转交。它支持 robot/world 坐标目标，说明可以进一步研究由仙工内部完成路径跟随的方案，避免把主机轮询接口作为该方案的每周期控制反馈。

这仍不能证明实时数据在内部引擎中的有效性，也不能证明已满足导航验收。两点目标不是任意 Nav2 多段路径；脚本没有明确的 Python 取消停车处理或运行时限，其 reset 只重置局部状态。内部引擎的到点、取消、断流和避障行为仍待验证，ROS FootprintStop 不会自动保护原生任务。

API1508 返回默认 `maxSpeed=1 m/s`、`maxRot=1`、`useOdo=1`、`backMode=1`、`coordinate=robot`、`x=y=theta=1`、`reachDist=0.005 m`、`reachAngle=3.14 rad`。其中 useOdo 的值与参数说明“默认为否”不一致，不能依赖默认参数开展试车。`hold_dir` 的界面单位是度，但其底层语义本轮未验证。
